# Add an AI feature safely

```text
Design and implement a small Wealth Copilot capability for <user-question>.
Keep the calculation and facts deterministic in a backend service. The
language-model seam may be represented by an interface, but do not require
an external API key.

The response must:
- use only the selected customer's data
- distinguish facts from explanations
- include a clear uncertainty or educational disclaimer where relevant
- have a deterministic fallback
- include tests for the main intent and an unsupported question

Explain how this could later be connected to a governed model gateway.
```
